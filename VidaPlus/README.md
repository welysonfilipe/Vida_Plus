# 🏥 Vida Plus

Sistema web para gestão de consultas médicas, telemedicina e administração hospitalar.

## 📋 Sobre o Projeto

Protótipo de alta fidelidade desenvolvido como Trabalho de Conclusão de Curso, implementando um sistema completo de saúde digital com interface para pacientes, profissionais de saúde e administradores.

## ✨ Funcionalidades

### Área do Paciente
- ✅ Agendamento de consultas (presencial e telemedicina)
- ✅ Histórico de consultas e tratamentos
- ✅ Visualização de resultados de exames
- ✅ Acesso à teleconsulta

### Área Administrativa
- ✅ Dashboard com métricas em tempo real
- ✅ Gestão de pacientes e profissionais
- ✅ Controle de internações
- ✅ Gestão de estoque hospitalar
- ✅ Prontuário eletrônico

## 🚀 Tecnologias

- **React 18** - Biblioteca JavaScript
- **React Router 6** - Roteamento SPA
- **Vite** - Build tool
- **react-big-calendar** - Calendário interativo
- **Moment.js** - Manipulação de datas

## 💻 Como Executar

### Pré-requisitos
- Node.js (versão 16 ou superior)
- npm ou yarn

### Instalação

1. Clone o repositório
```bash
git clone https://github.com/welysonfilipe/Vida_Plus.git
cd Vida_Plus
```

2. Instale as dependências
```bash
npm install
```

3. Execute o projeto
```bash
npm run dev
```

4. Acesse no navegador
```
http://localhost:5173
```
